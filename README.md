# Sistema de Gestión E-commerce

## Descripción
Sistema de gestión de comercio electrónico desarrollado en Go. Permite administrar usuarios, productos, inventario, carritos de compras, pedidos y reportes.

## Tecnologías utilizadas
- Lenguaje Go
- Visual Studio Code
- Archivos JSON para almacenamiento de datos

## Módulos del sistema

1. Gestión de usuarios: registro y consulta de usuarios.
2. Gestión de productos: registro y consulta de productos.
3. Gestión de inventario: entradas, salidas y control de existencias.
4. Carrito de compras: agregar productos y calcular totales.
5. Gestión de pedidos: registrar pedidos y actualizar sus estados.
6. Reportes: generación e historial de reportes generales.
